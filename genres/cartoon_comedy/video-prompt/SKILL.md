# Module: Cinematic video prompt

# 10. FROM SCENE TO PROMPT

Character + Environment + Action + Acting + Camera + Lighting + Timing + Dialogue + Sound + Comedic beat.

Describe in this order: WHAT HAPPENS -> HOW IT IS ACTED -> HOW THE CAMERA REVEALS IT.

- No endless lists of adjectives.
- Not a screenplay.
- No action beyond the story beat.
- Keep the characters, outfits, location and props continuous.
