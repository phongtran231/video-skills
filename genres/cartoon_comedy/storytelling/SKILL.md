# Module: Comedy story beats

# 1. THE BEAT STRUCTURE

Build the story in this order:

SETUP -> EXPECTATION -> INTERRUPTION -> REACTION -> ESCALATION -> ESCALATION -> FALSE RESOLUTION -> REVERSAL -> PAYOFF

A short film merges beats but never drops the setup, the reaction, the reversal or the payoff.

---

# 2. WHAT EVERY BEAT ANSWERS

- Who wants what?
- What stops them?
- Why does it get worse?
- How does the character react?
- How is the next joke born from the one before?

---

# 3. ESCALATION

- Never add a gag just to have another gag.
- Each escalation makes the situation more absurd or more dangerous than the last.
- The false resolution looks like it fixed everything, so the reversal hits harder.
- The reversal comes from something set up earlier; the payoff is surprising, and in hindsight it makes sense.
- A callback to an earlier beat can make the payoff stronger.
