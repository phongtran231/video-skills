Object tags: 4-8 short lowercase English tags (1-3 words each). The first tag is the concrete object noun (e.g. umbrella, phone, key, sword), never a generic label like "prop" or "weather prop". Then material (e.g. metal, fabric, wood, glass, plastic), era (exactly one of: {{> shared/era-tags}}), and style.
